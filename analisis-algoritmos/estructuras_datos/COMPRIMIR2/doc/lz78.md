# LZ78 — Lempel-Ziv 1978

> Diccionario de frases construido dinámicamente durante la compresión.

## Idea principal

LZ78 mantiene un diccionario de frases encontradas previamente. A medida que
recorre el texto, busca la frase más larga que ya esté en el diccionario y
emite un token que extiende esa frase con un nuevo símbolo.

Cada token es un par:

- `index` — referencia a una frase previa del diccionario
- `next_byte` — símbolo que extiende esa frase

## Ejemplo

Suponiendo la cadena `ABABABA`:

1. `A`  → token `(0, 'A')`  → agrega frase `A`
2. `B`  → token `(0, 'B')`  → agrega frase `B`
3. `AB` → token `(1, 'B')`  → agrega frase `AB`
4. `ABA`→ token `(2, 'A')`  → agrega frase `BA`

Salida de tokens:

```
(0, A)
(0, B)
(1, B)
(2, A)
```

## Implementación en este proyecto

- `src/lz78.h` / `src/lz78.c`
- Token fijo de 3 bytes: `uint16_t index` + `uint8_t next_byte`
- Descompresión reconstruye las frases usando el diccionario de tokens

## Características

- **Mejor caso:** datos con frases repetidas y reutilizables
- **Ventaja:** no necesita enviar el símbolo completo junto con cada frase previa
- **Complejidad:** O(n^2) en esta implementación ingenua

## Relación con otros LZ

- LZ77 usa referencias a la ventana histórica
- LZ78 usa un diccionario de frases explícito
- LZW emplea diccionario como LZ78, pero sólo envía códigos en lugar de símbolos
